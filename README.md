## ✨ О проекте

TaskFlow System — это десктопное приложение для управления задачами в тёмной зелёной теме, которое сочетает в себе:

- 📋 **Канбан-доску** — «К выполнению», «В работе», «На проверке», «Готово»
- 👤 **Локальные профили** — создавайте несколько профилей и переключайтесь между ними без паролей
- 🗂️ **Проекты и команду** — рабочее пространство для совместной работы
- 🌐 **Два микросервиса** — `IdentityServiceAPI` и `TaskServiceAPI` на ASP.NET Core

Проект учебный и находится в активной разработке.

## 🚀 Быстрый старт

### Требования

- **Windows 10/11**
- **Visual Studio** с рабочей нагрузкой *.NET desktop development*
- **.NET 10 SDK** — для API-сервисов

### Клиент

```bash
# Сборка через Visual Studio: откройте TaskFlowSystem.slnx и нажмите F5
# либо из консоли (путь к MSBuild у вашей версии Visual Studio):
msbuild TaskFlowSystem\TaskFlowSystem.csproj /p:Configuration=Debug
```

Готовый `.exe` появится в `TaskFlowSystem\bin\Debug\TaskFlowSystem.exe`.

### API-сервисы

```bash
dotnet run --project IdentityServiceAPI   # http://localhost:5210
dotnet run --project TaskServiceAPI       # http://localhost:5070
```

В режиме разработки OpenAPI-документация доступна по адресу `/openapi/v1.json`.

## 👤 Локальные профили

Регистрация полностью локальная — **без паролей, подтверждений и интернета**.

1. При запуске откроется **окно выбора профиля**.
2. Нажмите **«Новый профиль»**, укажите имя, описание (необязательно), выберите акцентный цвет и при желании добавьте фотографию.
3. Профиль создастся сразу — и вы попадёте на доску.
4. Переключиться между профилями можно в любой момент — клик по аватару в шапке.
5. Изменить имя, описание, цвет или фотографию можно кнопкой ✎ в окне выбора профиля.

Профили хранятся в:

```
%APPDATA%\TaskFlowSystem\profiles.json
```

Фотографии профилей — в подпапке `avatars` рядом с файлом профилей. Исходные
изображения не изменяются: приложение сохраняет уменьшенную локальную копию.
